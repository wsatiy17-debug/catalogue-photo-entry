The Lumin Kettle: a studio catalogue photograph of an impossible gadget — a matte-white electric kettle that pours liquid golden light into a plain white mug, shot on a seamless pale-grey studio backdrop with soft diffused light.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the pre-rendered `entry.png` (1024x1024, 516,497 bytes) to `/output/entry.png`. No network, no dependencies, standard library only.
